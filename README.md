# ThemePlanner Wedding Client Inquiry Website

A responsive front-end website inspired by the supplied ThemePlanner-style mobile UI.

## Included
- ThemePlanner-inspired cream / blush / sage / dark-green visual system
- App-like home page
- Bespoke E-Invites, illustrations, stationery and gifts categories
- Full 9-step wedding client inquiry flow
- Same core inquiry content as the previous version:
  1. Your Wedding
  2. What Are We Creating?
  3. Your Digital Invite
  4. Stationery Suite
  5. The Investment
  6. The Timeline
  7. How Should It Feel?
  8. The Story
  9. The Wardrobe Edit
- Responsive mobile/tablet/desktop layout
- Progress bar
- Browser draft saving with localStorage
- JSON download after submission

## Run
Open `index.html` in a browser.

## Production integration
Replace the submit handler in `app.js` with your API, Google Sheets, Airtable, Notion, CRM, email service, or Tally endpoint.
